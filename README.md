# UC San Diego Student Founder Funding Opportunities

Static GitHub Pages site listing curated grants, pitch competitions, accelerators and fellowships for
UC San Diego student founders. Design follows ucsd.edu branding (navy / gold, condensed uppercase headings)
and the card/tab layout of studentfounderhq.com.

Live: https://eirik-wg.github.io/ucsd-opportunities/

## How the data flows

```
Reviewed workbook (Reviewed_2026)  ──export_site_data.ps1──►  data/opportunities.json  ──►  website
          │
          └── (planned) Airtable base = source of truth ──► website (direct API) + newsletter
```

- `data/opportunities.json` is generated by `export_site_data.ps1` (PowerShell + Excel COM) from
  `20260929_Funding opportunities_reviewed.xlsx`. It keeps only active Tier 1–2 opportunities (max 80),
  sorted by tier then deadline.
- The site computes status client-side from `deadline` + `deadlineKind`:
  - `rolling` → **Open · rolling**
  - `confirmed` and date in the future → **Open** / **Closes in N days**
  - `expected` (projected from last cycle) and date in the future → **Upcoming / expected**
  - date in the past → **Closed** (shown in "Recently closed" for 120 days)

### Refreshing the data

```powershell
powershell.exe -ExecutionPolicy Bypass -File "export_site_data.ps1"
git add data/opportunities.json
git commit -m "Refresh opportunities data"
git push
```

## Airtable as source of truth

`app.js` reads Airtable directly when `CONFIG.airtable.apiKey` and `baseId` are set. The expected field
names match the workbook columns: `Program Title`, `Program Description`, `Type`, `Funding Amount/Prize Amount`,
`Next Deadline`, `Estimated Deadline Date`, `Student Startup Fit`, `Founder Stage`, `Best For`,
`Eligibility Label`, `Priority Tier`, `Website link`, plus optional `Organizer`, `Funding Model`, `Deadline Kind`,
`Geography`, `Industry`, `Eligibility` (multi-line), `UCSD Run`.

Do **not** commit a read/write Airtable token in browser JavaScript. For production either:

1. run a scheduled GitHub Action that pulls Airtable and rewrites `data/opportunities.json`, or
2. proxy the Airtable API through a small serverless function that holds the token.
